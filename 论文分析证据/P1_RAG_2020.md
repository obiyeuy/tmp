## 2. 标题

- **原文标题**：Retrieval-Augmented Generation for Knowledge-Intensive NLP Tasks
- **英文词数**：把连字符复合词算作 1 个词时为 **6 词**（Retrieval-Augmented / Generation / for / Knowledge-Intensive / NLP / Tasks）；拆开连字符计为 8 词。
- **结构**：名词短语，形式为"方法 + for + 应用范围"，不是完整句子，也不是问句。
- **是否包含方法名**：包含方法名的全称 "Retrieval-Augmented Generation"。缩写 RAG 不在标题里，摘要第 5 句才首次出现。
- **是否包含关键词**：包含 retrieval、generation、knowledge-intensive、NLP 等检索关键词。

| 评价标准 | 判断 | 说明 |
|---|---|---|
| 准确 | 基本准确 | 实验覆盖开放域问答、生成式问答、Jeopardy 出题和 FEVER 事实核验（第 3 节），与 "Knowledge-Intensive NLP Tasks" 相符。标题没有体现"知识源为 Wikipedia""基于 seq2seq 预训练模型"这两个限定条件（第 2–3 节），范围偏宽。 |

### 3.3 摘要检查项
- **结构**：背景（S1–S3）→ 不足（S4）→ 方法（S5–S7）→ 结果（S8–S9）。结构完整，但**没有单独的结论或意义句**。S9 是结果句，不是对研究意义的总结；正文第 4.5 节展示的"更换索引即可更新知识"（index hot-swapping）这一卖点也没有写进摘要，而 S3 恰好提出了"知识更新"问题，摘要对这个问题没有回应。
- **结果是否量化**：**只有定性描述，摘要中没有任何具体数值**。S8 只说"三个任务 SOTA"，没有 EM 分数；S9 用 "more specific, diverse and factual"，没有给出 Table 4 人工评测比例或 Table 5 多样性数值。引言最后一段反而给出了 FEVER "within 4.3%" 这样的数字（第 1 节）。
- **引用 / 图表**：摘要中无引用、无图表编号（原文未出现）。
- **"novel/first/state-of-the-art" 类用词**："novel"、"first" 原文未出现；"state-of-the-art / state of the art" 共出现 **3 次**（S1 描述前人模型、S8 描述本文结果、S9 描述基线）。
- **摘要与正文不一致**：摘要 S8 说 "three open domain QA tasks"，第 4.1 节写成 "On all four open-domain QA tasks, RAG sets a new state of the art (only on the T5-comparable split for TQA)."。按 Table 1，TQA 标准测试集上 DPR 为 57.9，高于 RAG-Seq. 的 56.8，所以"四个任务"的说法要靠括号里的限定条件才成立，与摘要的口径不同。
- **缩写**：RAG 在 S5 首次出现时给出了全称（规范）；seq2seq（S6）、QA（S8）、NLP（S1）在摘要中没有展开。

## 8. 实验（第 3–4 节及附录）

### 8.1 数据集（第 3 节；附录 I Table 7）

- 问题生成：Jeopardy，使用 SearchQA 的划分，"100K train, 14K dev, and 27K test"（3.3 节）。
